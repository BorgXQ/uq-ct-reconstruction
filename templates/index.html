How does the drawing become ground truth?

The editor is a high-resolution drawing. The backend averages it onto the selected grid and normalizes the values to 0–1. The frozen numerical grid is the ground truth for later simulated CT measurements. It is stored separately, so further drawing does not change an existing experiment’s image.

Rows increase downward; columns increase rightward. Spatial coordinates cover [−1, 1] in both directions, with vertical coordinates increasing upward. All-black images are valid. These densities are simulation quantities, not calibrated medical measurements.

Snapshots survive a page reload while this server is running, but are lost on server restart. The store holds up to 50 snapshots. The drawing and undo history are not saved on reload.

Freeze a snapshot, then open Measure to create a scan. Uncertainty and Validation arrive in M3–M5.
